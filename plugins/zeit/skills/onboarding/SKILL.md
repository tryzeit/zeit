---
name: onboarding
description: Connect to Zeit or create an account through its browser email-code flow. Use when the user wants to get started with Zeit or continue onboarding.
---

Continue setup in the current conversation. Call `get_account` to check the
connection. If authentication is required, use the host's normal MCP OAuth
connection flow for Zeit. This flow handles both new and existing accounts.
Do not require the user to create an account separately.

The browser asks for email, sends a verification code, and shows the connecting
application and permissions. The user enters the code there and selects
**Verify and connect**. Zeit creates or signs in the account and returns to the
host through OAuth. Never ask for passwords or verification codes in chat, read
their inbox for a code, or ask them to paste tokens. Do not construct an OAuth
URL yourself; use the authorization URL generated by the host.

Wait for the host's connection result. Then call `get_account` again and confirm
the returned email. If the browser flow was cancelled or failed, report that
connection is incomplete. Do not automatically resend codes or repeatedly
restart authorization. An installed plugin alone is not a connected account.

If Zeit's tools are missing, use host tool discovery and an available
host-supported plugin or MCP refresh, then rediscover once. Do not start a
separate app-server process, edit unrelated settings, repeatedly reinstall, or
claim a refresh happened without confirmation. If tools remain unavailable,
explain the limitation and offer a new chat. Do not create a duplicate MCP server
or modify the host's internal credential store.
